# Todo-list

##### Project Duration: May 2024 – Jun 2024

- Developed a feature-rich TODO app inspired by Microsoft TODO using React.js, TypeScript, Material-UI.
- Implemented Redux for robust state management and integrated React Router for smooth navigation.
- Created a highly interactive, scalable, and maintainable application.
- Optimized DOM manipulation for enhanced performance.
- Conducted cross-browser compatibility testing to ensure consistency.
